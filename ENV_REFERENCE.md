# Environment Variables (set in Vercel project settings)

```bash
# Resend (contact form emails). Optional: without it, messages are logged to
# Vercel function logs instead of emailed.
RESEND_API_KEY=
# Where contact emails go / come from (LEAD_FROM_EMAIL needs a Resend-verified domain)
LEAD_TO_EMAIL=info@nexuschicago.com
# LEAD_FROM_EMAIL=Nexus Chicago Website <noreply@nexuschicago.com>
```
